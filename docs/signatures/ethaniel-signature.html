Install in Gmail

For Ethaniel (Gmail)

  1. Click once inside the preview box above to auto-select the signature.
  2. Copy: Cmd+C (Mac) or Ctrl+C (Windows).
  3. In Gmail: click the gear icon (top right) → See all settings.
  4. On the General tab, scroll to Signature → click + Create new, give it a name (e.g. “AxisPoint”), then click inside the editor.
  5. Paste: Cmd+V / Ctrl+V. The formatted signature should appear. Scroll down and click Save Changes.

Also works in Spark

Spark HTML mode (if needed)

  2. Click Signature, switch to HTML mode.
